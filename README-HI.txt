AI Forex Pro - Android starter project (v0.1.0)

Is ZIP mein Android app ka starter source code hai. Yeh abhi APK nahi hai.

Abhi kya bana hai:
- Dark theme dashboard
- Demo / Real mode ka UI toggle (Real trading execute nahi hoti)
- MT5 aur CoinDCX connection placeholders
- AI Assistant screen placeholder
- UPI deposit aur NEFT/RTGS withdrawal ke UI placeholders
- Markets aur Account screens

Abhi kya baaki hai:
- MT5 broker/server ke official integration details
- CoinDCX API integration (API keys ko app mein hard-code nahi karna; secure backend chahiye)
- Secure login, KYC/AML, payment partner aur withdrawal compliance
- AI backend, live market data, order/risk controls
- Testing, signing aur APK build

APK banane ke liye Android SDK/Android Studio aur compatible internet-enabled build environment chahiye.
Is project ko Android Studio mein open karke Gradle sync karein aur Build > Build APK(s) chalayein.

IMPORTANT: Is starter project se real-money trade, deposit ya withdrawal nahi hota. Demo UI ko real trading samajhkar paisa transfer na karein.
